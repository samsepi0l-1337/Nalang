# 진동 측정기 프로토타입 사양

데드라인 구현 범위만 다룬다. 벨트 노후화/윤활 진단 모델, 다중 장비, AP 모드,
데이터 아카이브, 부저 소프트웨어·임계값 알람은 하지 않는다.

## 1. 목적

벨트 노후화나 윤활 미흡 시 평소와 다른 진동·소음이 난다. 이 프로토타입은 그
징후를 사람이 볼 수 있게 **진동을 측정·표시**한다.

자동 진단(분류, 학습, 주파수 밴드 분석)은 이번 범위가 아니다.

## 2. 하드웨어

| 항목       | 결정                                                               |
| ---------- | ------------------------------------------------------------------ |
| 보드       | Raspberry Pi Zero 2 W                                              |
| OS         | Raspberry Pi OS 64-bit                                             |
| 센서       | ADXL355B 브레이크아웃, SPI, 전원 3.3 V. 전면 실크 기준            |
| 디스플레이 | I2C 1602 (16×2 문자 LCD), I2C 백팩 VCC는 **3.3 V** (5 V 넣지 않음) |
| 부저       | 데드라인 소프트웨어·배선 범위 밖. 종류는 제작자가 맞춘다           |
| 대수       | 1대                                                                |
| 네트워크   | 기존 Wi-Fi에 클라이언트로 접속                                     |
| 솔더링     | 아직 없음. 이 문서의 SPI/I2C 핀을 기준으로 맞춘다                  |

센서는 Analog Devices EVAL 보드가 아니라 **ADXL355B** 칩이 올라간 서드파티
모듈이다. 배선은 전면 실크를 따른다.

- 전면: `docs/assets/adxl355-front.png`
- 포장 상태(후면·백): `docs/assets/adxl355-breakout.png`

전면 구멍은 두 줄이다. 칩 각인 `ADXL355B`. 보드 하단 실크 `ADXL355`.

윗줄 7홀 (칩 위, 왼쪽→오른쪽): `CL-SCL`, `DA-SDA`, `SA0`, `SCK`, `INT2`,
`VCC`, `GND`.

아랫줄 5홀 (칩 아래, 왼쪽→오른쪽): `DRDY`, `INT1`, `MISO`, `MOSI`, `CS`.

축 실크: Y는 윗줄 방향, X는 보드 평면, Z는 보드에서 수직으로 나옴. 소프트웨어는
절댓값이 큰 축을 쓰므로 장착 방향은 제작자가 정한다.

동봉 7핀 헤더는 윗줄용이다. SPI 전원·클럭은 윗줄(`VCC`, `GND`, `SCK`), 데이터는
아랫줄(`MISO`, `MOSI`, `CS`)에 있으므로 **두 줄 모두** 헤더 또는 전선을 납땜한다.

## 3. GPIO 배선

기준 핀맵: `docs/assets/pi-zero-2w-gpio.png` (Pi Zero 2 W 40핀).

이미지의 GPIO 17(핀 11) “Chip Enable” 표기는 일반 GPIO다. Linux `spidev` CS로는
쓰지 않는다. SPI0 CS는 **CE0 = GPIO 8 / 핀 24**를 쓴다.

### 3.1 ADXL355 (SPI0, 3.3 V)

전면 실크 → Pi. SPI만 사용한다. 센서 I2C 핀(`CL-SCL`, `DA-SDA`, `SA0`)은 Pi I2C
(1602)에 연결하지 않는다.

| 센서 실크 | 줄   | 기능     | BCM GPIO | 물리 핀    | 비고                        |
| --------- | ---- | -------- | -------- | ---------- | --------------------------- |
| VCC       | 윗줄 | 전원     | —        | 1 (3.3 V)  | 5 V 금지                    |
| GND       | 윗줄 | GND      | —        | 25         |                             |
| SCK       | 윗줄 | SCLK     | 11       | 23         | 고정                        |
| MOSI      | 아랫줄 | MOSI   | 10       | 19         | 고정                        |
| MISO      | 아랫줄 | MISO   | 9        | 21         | 고정                        |
| CS        | 아랫줄 | CS     | 8        | 24         | SPI0 CE0 → `/dev/spidev0.0` |
| DRDY      | 아랫줄 | —      | —        | 연결 안 함 | 소프트웨어 폴링             |
| INT1      | 아랫줄 | —      | —        | 연결 안 함 |                             |
| INT2      | 윗줄 | —        | —        | 연결 안 함 |                             |
| CL-SCL    | 윗줄 | I2C      | —        | 연결 안 함 |                             |
| DA-SDA    | 윗줄 | I2C      | —        | 연결 안 함 |                             |
| SA0       | 윗줄 | I2C 주소 | —        | 연결 안 함 |                             |

### 3.2 I2C 1602 (I2C1, 3.3 V)

| 기능 | BCM GPIO | 물리 핀    | 비고                                  |
| ---- | -------- | ---------- | ------------------------------------- |
| VCC  | —        | 17 (3.3 V) | 백팩 5 V 금지. 센서 3.3 V와 핀을 나눔 |
| GND  | —        | 6          |                                       |
| SDA  | 2        | 3          | 고정                                  |
| SCL  | 3        | 5          | 고정                                  |

SDA/SCL을 3.3 V로 맞춰 Pi GPIO를 보호한다. I2C 주소는 실행 시 `i2cdetect`로
찾는다(흔한 값: `0x27`, `0x3F`). 3.3 V에서 1602 대비·백라이트가 약하면 대비
트리만 조정하고, 백팩 VCC는 3.3 V로 유지한다.

### 3.3 부저

데드라인에 연결·제어하지 않는다. GPIO를 예약하지 않는다.

## 4. 측정 규칙

- 샘플링: ADXL355 ODR 1000 Hz, 범위 ±8.192 g.
- 축: 장착 방향이 바뀌므로 XYZ 중 **절댓값이 큰 축**을 쓴다. 1초마다 축을 다시
  고른다.
- 표시값: 선택한 축의 1초 RMS(g)와 1초 피크(g).
- 웹 그래프: 최근 60초 RMS 시계열. 1초마다 점 1개. 원시 파형(1000 Hz)은 폰으로
  보내지 않는다.
- 단위: g.
- 알람 임계값 없음. 측정값만 보여 준다.

Zero 2 W에서 1000 Hz 원시 파형을 WebSocket으로 흘리면 감당이 안 되므로, 보드에서
RMS를 계산한 뒤 웹에는 1 Hz로만 보낸다.

## 5. 화면·동작

### 5.1 1602 LCD

- 1행: `RMS 0.123 g`
- 2행: `PK  0.456 g` 및 선택 축 (`X`/`Y`/`Z`)

갱신 주기 1초.

### 5.2 모바일 웹

- 기존 Wi-Fi에서 Pi에 접속. 주소는 Pi IP, 포트 5000.
- 필요한 것: **진동 그래프(RMS 60초)** 만. 측정 표시만 한다.
- 인증, 다중 장비, 로그 다운로드, 알람 표시 없음.

### 5.3 자동 시작

프로토타입에서만 systemd 서비스로 부팅 시 측정·웹을 올린다. 한 대 기준.

## 6. 소프트웨어 스택

언어: Python 3 (OS 64-bit 기본).

| 영역   | 라이브러리                            | 용도               |
| ------ | ------------------------------------- | ------------------ |
| 센서   | `spidev`                              | ADXL355 SPI        |
| LCD    | `RPLCD` + `smbus2`                    | I2C 1602 (PCF8574) |
| 연산   | `numpy`                               | RMS/피크           |
| 웹     | `Flask`, `Flask-SocketIO`, `eventlet` | 실시간 전송        |
| 프론트 | Chart.js (CDN)                        | RMS 그래프         |

쓰지 않는 것: `adafruit-blinka`, `board`, `RPi.GPIO`, `gpiozero`(부저 없음).

프로세스: 센서 폴링 스레드가 1초 RMS를 만들고, 메인 프로세스가 LCD와 WebSocket에
반영한다.

## 7. 이번 범위에 넣지 않는 것

- 벨트/윤활 자동 판정, FFT, 학습
- 부저 소프트웨어, 임계값 알람, 부저 배선
- 데이터 파일 저장, 외부 서버
- Wi-Fi AP, 여러 대
- DRDY / INT1 / INT2, 센서 I2C 핀 연결

## 8. 결정 기록

| 항목          | 결정                                                      |
| ------------- | --------------------------------------------------------- |
| 센서 보드     | ADXL355B 전면 실크 기준. `docs/assets/adxl355-front.png` |
| LCD 백팩 전원 | 3.3 V. 레벨 시프터 없음                                   |
| 부저 종류     | 제작자가 맞춤. 데드라인 소프트웨어 무관                   |
| 부저·임계값   | 데드라인에 구현하지 않음. 측정만                          |
| LCD·그래프    | 1초 RMS, 60초 차트 유지                                   |

구현에 필요한 하드웨어·동작은 이 문서로 닫힌다. I2C 주소는 장비에서 스캔한다.
